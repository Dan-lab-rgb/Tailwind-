Tailwind em ação

O framework não está só instalado. Ele constrói a interface.

Layout, cores, espaçamentos, responsividade, bordas, transparência, estados e transições deste site foram montados com classes utilitárias. O JavaScript ficou restrito às interações.

grid lg:grid-cols-3 hover:-translate-y-1 backdrop-blur-xl rounded-3xl

Utility-first

Pequenas classes são combinadas até formar componentes completos.

Responsividade

Prefixos como sm:, md: e lg: adaptam a página.

Estados

hover:, focus: e group-hover: criam interações.

Preflight

Uma base consistente reduz diferenças iniciais entre os estilos padrão dos navegadores.
